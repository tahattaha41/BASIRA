## نطاق المنتج
- ثمانية أقسام معرفة.
- خمس ألعاب ذهنية أولية.
- سؤال اليوم وتحديات المعرفة.
- اللعب كزائر، مع حساب اختياري لحفظ التقدم.
- محتوى أصلي موثق ومراجع بشريًا.

## حالة المشروع
المشروع قيد التطوير. وجود قالب أو نموذج واجهة لا يعني اكتمال الوظائف أو نشرها على Blogger. راجع لوحة الحالة قبل وصف أي ميزة بأنها جاهزة.

## الطلبات والتطوير
سجّل الطلبات الجديدة عبر [نموذج طلب جديد](.github/ISSUE_TEMPLATE/new-request.yml)، ونفّذ التغييرات عبر Pull Requests. يجب أن يذكر كل PR ما تم اختباره وما لم يتم اختباره.

## Blogger
اسم العلامة هو **BASIRA | بصيرة**. عنوان Blogspot عنوان تقني مستقل ويمكن اختيار عنوان بديل متاح دون تغيير اسم العلامة.
