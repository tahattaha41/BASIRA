## قرارات مؤجلة

- عنوان Blogger الفرعي المتاح؛ لا يغيّر اسم العلامة.
- مزود الحسابات النهائي.
- اعتماد سياسة النقاط النهائية.
- توقيت إطلاق التحديات اليومية/الأسبوعية.
- اعتماد الإنجليزية كلغة واجهة كاملة.
- أي خدمات مدفوعة أو APIs تحتاج رصيدًا.

## قاعدة تغيير القرار

لا يُحذف قرار سابق بصمت. عند تغييره:
1. أضف قرارًا أحدث مع التاريخ والسبب.
2. حدّث المرجع والحالة.
3. اذكر الملفات/الاختبارات المتأثرة في PR.
4. احتفظ بالتاريخ السابق لتجنب تكرار النقاش.
