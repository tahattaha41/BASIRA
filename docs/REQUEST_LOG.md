## آلية الإضافة

- كل Issue جديد يُضاف تلقائيًا بواسطة GitHub Actions.
- الطلبات التي تصل عبر محادثة خارج GitHub يجب تسجيلها في Issue أو تحديث هذا الملف في نفس PR الذي ينفذها.
- لا تُعتبر الطلبات المسجلة منجزة حتى يربط بها PR أو commit واختبار مناسب.
