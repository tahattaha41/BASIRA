## آلية الإضافة

- سيُضاف كل Issue تلقائيًا بعد وجود workflow في الفرع الافتراضي وتشغيله بنجاح؛ هذا الشرط لم يتحقق بعد لأن PR #5 يستهدف platform-dev بينما الفرع الافتراضي main.
- الطلبات التي تصل عبر محادثة خارج GitHub لا تصل تلقائيًا؛ يسجلها منفذ العمل كـ Issue أو يحدّث هذا الملف في PR التنفيذ.
- لا تُعتبر الطلبات المسجلة منجزة حتى يربط بها PR أو commit واختبار مناسب.
