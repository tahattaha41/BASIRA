# نشر BASIRA إلى Blogger

آخر مراجعة: 2026-11-23

## ما يحدث تلقائياً الآن

عند أي push إلى `main`:
1. GitHub Actions يشغّل `basira-ci.yml`.
2. يبني القالب والصفحات من ملفات `src/`.
3. يشغّل فحوص XML والمحتوى والروابط والواجهة والألعاب.
4. يحفظ ملف `basira-release.zip` كـ workflow artifact.

هذا CI وليس نشرًا إلى Blogger. نجاحه يعني أن البناء والاختبارات نجحت، ولا يعني أن الموقع الحي تغير.

## ما لا يمكن أتمتته عبر Blogger API الرسمي

Blogger API v3 يوثق موارد Blogs وPosts وPages وComments وUsers وغيرها، ولا يوثق مورداً للقوالب أو طريقة لرفع ملف XML للقالب.

المصدر الرسمي:
- https://developers.google.com/blogger/docs/3.0/getting_started
- https://developers.google.com/blogger/docs/3.0/reference

لذلك لا يمكن نشر تغييرات `src/theme.tpl.xml` إلى قالب المدونة مباشرة عبر API الرسمي. المسار المدعوم في المشروع:
1. افتح آخر artifact باسم `basira-release` من GitHub Actions.
2. استخرج `basira-theme.xml` أو استخدم `dist/theme.xml` من البناء.
3. في Blogger افتح **المظهر/السمة ← استعادة** وارفع الملف.
4. افحص الصفحة الرئيسية و`?m=1` والمقالات والصفحات على الهاتف والكمبيوتر.

لا توجد أداة رسمية في هذا المستودع تستطيع تنفيذ خطوة رفع القالب تلقائياً.

## الصفحات الثابتة

الملف `.github/workflows/basira-blogger-pages.yml` يدوي حالياً عبر `workflow_dispatch`:
- `plan`: معاينة بلا إرسال إلى Blogger.
- `apply` مع تأكيد صريح: إنشاء الصفحات المفقودة.
- `update_existing`: تحديث محتوى الصفحات الموجودة.

سجل التشغيل 44966350885 كان `MODE=plan` و`CONFIRM=NO`؛ لم ينشر أي صفحة.

قبل تفعيل أي نشر آلي للصفحات:
- يجب اختبار OAuth وBlog ID.
- يجب منع صفحة الاتصال من النشر طالما `BASIRA_CONTACT_EMAIL` غير صالح.
- يجب تحديد سياسة التحديث للصفحات الموجودة حتى لا تُستبدل تعديلات يدوية غير محفوظة في GitHub.
- يجب التحقق من روابط Blogger الفعلية قبل إضافتها إلى `src/site.json:published`.

## المقالات

المقالات الثمانية في `content/articles/` مسودات بمصادر وتحتاج مراجعة المالك. لا يوجد نشر آلي لها، ولا ينبغي ربط push عام بنشرها كمقالات حية.

## القاعدة التشغيلية

- تعديل المصدر على GitHub → بناء واختبارات تلقائية.
- تغيير القالب → تنزيل artifact ورفعه يدوياً إلى Blogger.
- الصفحات الثابتة → نشرها عبر workflow مخصص بعد مراجعة الإعدادات وسياسة التحديث.
- المقالات → تبقى مسودات حتى المراجعة والموافقة.
