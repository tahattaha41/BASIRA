# BASIRA — التثبيت مرة واحدة والتحديث التلقائي

آخر تحديث: 2026-11-23

## التثبيت الأول
ارفع ملف `BASIRA-Blogger-Theme.xml` مرة واحدة من Blogger: **المظهر ← استعادة ← تحميل**.

القالب يحمل CSS وJavaScript من:
- `https://cdn.jsdelivr.net/gh/tahattaha41/BASIRA@main/dist/basira.css`
- `https://cdn.jsdelivr.net/gh/tahattaha41/BASIRA@main/dist/basira.js`

## التحديثات التلقائية
بعد كل push إلى `main`:
1. GitHub Actions يبني الموقع ويختبر XML والمحتوى والواجهة والألعاب.
2. بعد نجاح CI، يتم تحديث `dist/basira.css` و`dist/basira.js` على الفرع الرئيسي.
3. القالب المثبت في Blogger يحمّل النسخ الجديدة دون رفع XML مرة أخرى.
4. بعد نجاح CI، يشغّل `basira-auto-sync-pages.yml` مزامنة الصفحات الثابتة عبر Blogger API: ينشئ الصفحات الناقصة ويحدّث الموجودة بالعنوان نفسه.

قد يتأخر ظهور التحديث قليلاً بسبب التخزين المؤقت للمتصفح أو GitHub.

## الحدود التي لا يمكن تجاوزها بواجهة Blogger الرسمية
- التغييرات في هيكل `src/theme.tpl.xml` نفسه تحتاج رفع XML مرة أخرى؛ Blogger API لا يوفر واجهة لرفع القوالب أو تفعيلها.
- CSS وJavaScript والتغييرات المدعومة في منطق الألعاب والتطبيق تتحدث تلقائياً من GitHub.
- الصفحات الثابتة تتحدث تلقائياً بعد CI الناجح.
- المقالات الثمانية في `content/articles/` تظل مسودات ولا تُنشر آلياً قبل مراجعة المالك.
- لا تُنشر صفحة الاتصال ما دام البريد البديل موجوداً.

## أسرار Actions المطلوبة لمزامنة الصفحات
- `BLOGGER_BLOG_ID`
- `BLOGGER_CLIENT_ID`
- `BLOGGER_CLIENT_SECRET`
- `BLOGGER_REFRESH_TOKEN`
- `BASIRA_CONTACT_EMAIL` (مطلوب قبل نشر صفحة الاتصال)

إذا كانت أسرار OAuth الأربعة غير متاحة، يتخطى Workflow مزامنة Blogger دون نشر.

## ضمانات
- لا حذف لأي صفحة.
- لا نشر تلقائي للمقالات المسودة.
- لا تعديل للإدارة أو تسجيل الدخول.
- تحديث الصفحات الموجودة يستبدل محتواها بنسخة GitHub المطابقة للعنوان؛ لا تحتفظ بتعديلات يدوية خارج المستودع إذا كنت تريد مزامنتها.
- نجاح CI لا يثبت عرض Blogger الحقيقي؛ يجب اختبار أول رفع يدوياً.

## اللغات وصفحات المعلومات
- صفحات من نحن، كيف نتحقق، سياسة التحرير، الخصوصية، الشروط، واتصل بنا تحتوي نسختين عربية وإنجليزية، ويُظهر زر اللغة النسخة المناسبة.
- ترجمة واجهة الألعاب والأسئلة: الأسئلة الحالية عربية؛ لا ندّعي وجود بنك أسئلة إنجليزي مكتمل.
- رابط الإدارة في تذييل الموقع يفتح لوحة Blogger الرسمية. لا توجد لوحة CMS مخصصة داخل القالب؛ Blogger لا يوفر قاعدة بيانات أو خادماً آمناً لتخزين صلاحيات الإدارة داخل XML/JavaScript. لا تُضمّن OAuth secrets أو كلمات مرور في القالب.
