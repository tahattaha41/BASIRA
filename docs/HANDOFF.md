## ملفات المصدر

- `src/theme.tpl.xml`: قالب Blogger.

- `src/i18n/`: نصوص الواجهة العربية والإنجليزية.
- `src/pages/`: محتوى الصفحات الثابتة.
- `src/site.json`: إعدادات الهوية والأقسام والألعاب وقائمة المسارات المنشورة.
- `content/articles/`: ثمانية مقالات مسودة، لا تُنشر قبل مراجعة المالك.
- `brand/`: الشعارات ورسومات SVG.
- `scripts/build.py`: توليد `dist/theme.xml` و`dist/pages/`.
- `preview/`: بيئة/ملفات اختبار محلية محفوظة بالمستودع، وليست الموقع الحي.

## النشر إلى Blogger

يوجد workflow باسم `basira-blogger-pages.yml` يعمل يدوياً عبر `workflow_dispatch` فقط. سجل التشغيل 44966350885 نجح، لكنه كان في وضع `MODE=plan` و`CONFIRM=NO`؛ أي لم يرسل أي شيء إلى Blogger.

القيود:
1. Blogger API v3 يدعم إدارة Posts وPages ولا يوفّر مورداً لرفع قالب XML.
2. رفع `dist/theme.xml` ما زال يدوياً من لوحة Blogger.
3. نشر الصفحات الثابتة يمكن أتمتته عبر OAuth، لكن workflow الحالي يدوي وليس push deployment.
4. بريد الاتصال غير مضبوط في `src/site.json`، وصفحة الاتصال لا تعتبر جاهزة.
5. لا تُفعّل روابط الصفحات في `published` إلا بعد فحص الرابط الحقيقي.
6. لا تنشر مقالات `content/articles/` تلقائياً؛ هي مسودات تنتظر المراجعة.

## المطلوب قبل النشر الكامل

- رفع القالب على مدونة اختبار والتحقق من الرئيسية و`?m=1` والمقالات والصفحات والاتجاهين.
- مراجعة مقالات المحتوى الثمانية.
- توفير بريد تواصل صالح قبل نشر صفحة الاتصال.
- اختبار السحب واللمس على هاتف حقيقي.
- اعتماد الروابط الفعلية للصفحات ثم تحديث `src/site.json`.
