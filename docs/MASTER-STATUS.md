## النشر والتحديث التلقائي

### القالب
- بناء القالب ينتج `dist/theme.xml`.
- Blogger API v3 لا يعرض موردًا لرفع أو تحديث XML theme؛ لذلك أي تغيير في بنية `src/theme.tpl.xml` يتطلب رفع ملف XML يدويًا من لوحة Blogger.
- بعد تثبيت القالب، يمكنه تحميل CSS وJavaScript من `dist/basira.css` و`dist/basira.js` على jsDelivr المرتبط بفرع main. لا يثبت ذلك وحده أن Blogger يعرض النسخة الصحيحة؛ يلزم اختبار حي.

### الصفحات الثابتة
- يوجد Workflow باسم `BASIRA auto-sync approved Blogger pages` يعمل بعد اكتمال CI على main.
- تشغيل المزامنة رقم [45136359740](https://github.com/tahattaha41/BASIRA/actions/runs/45136359740) اكتمل بنجاح بتاريخ 2026-11-23. سجل GitHub Actions يؤكد تحديث الصفحات الخمس الموجودة عبر Blogger API.
- يتطلب المزامنة أسرار GitHub Actions: `BLOGGER_BLOG_ID`, `BLOGGER_CLIENT_ID`, `BLOGGER_CLIENT_SECRET`, `BLOGGER_REFRESH_TOKEN`.
- `BASIRA_CONTACT_EMAIL` مطلوب لتوفير بريد صفحة الاتصال.
- المزامنة الحالية تستخدم `--update`؛ أي أنها قد تستبدل محتوى صفحة Blogger الموجودة إذا تطابق عنوانها. يجب إبقاء مصدر المحتوى المعتمد في GitHub وعدم إجراء تعديلات يدوية متعارضة على تلك الصفحات.
- لا توجد مزامنة تلقائية للمقالات الثمانية، ولا نشر تلقائي لها.

### إدارة الموقع
رابط Blogger الرسمي ليس لوحة إدارة مخصصة. إدارة الصفحات والمنشورات تتم عبر حساب Blogger. إنشاء لوحة إدارة مالك داخل BASIRA يحتاج خادمًا آمنًا ومصادقة وتخزينًا؛ لا يجوز وضع OAuth secrets أو كلمات مرور داخل XML أو JavaScript. لم يتم بناء هذه اللوحة بعد.

## نتائج الاختبارات المتاحة
- PR #23 اجتاز CI بتاريخ 2026-11-23: البناء، preflight، اختبارات القالب، المحتوى، مسار النشر offline، اختبارات الواجهة واللغات والبحث والمقاسات، وتجربة لعب فعلية.
- خطوة Blogger API read-only تم تخطيها لعدم توفر/عدم استخدام الأسرار في ذلك التشغيل؛ لذلك لا يوجد إثبات اتصال أو نشر حي.
- بعد الدمج إلى main وتحديث الشعار، يجب انتظار تشغيل CI جديد والتحقق من نتيجته.
- لم يتم إثبات اختبار متصفح حي على Blogger أو رفع القالب في هذه المراجعة.

## المتبقي بالترتيب
1. رفع `dist/theme.xml` يدويًا مرة واحدة في Blogger، ثم فحص الصفحة الرئيسية على الهاتف والكمبيوتر، العربية والإنجليزية، الفاتح والداكن.
2. التحقق من تحميل CSS/JS من jsDelivr عبر المتصفح ومن سلامة MIME/الاستجابة على الموقع الحي.
3. التأكد من أسرار Blogger OAuth في GitHub Actions دون كشف قيمها، ثم التحقق من تشغيل مزامنة الصفحات فعليًا.
4. إدخال بريد اتصال حقيقي في Secret `BASIRA_CONTACT_EMAIL` ومراجعة صفحة الاتصال.
5. إعداد بنك أسئلة إنجليزي أصلي ومراجع، وليس ترجمة أزرار الواجهة فقط.
6. استكمال لوحة إدارة مالك آمنة إذا تم اعتماد backend مناسب؛ لا تُعامل لوحة Blogger الرسمية كبديل عنها.
7. مراجعة المقالات الثمانية ومصادرها وصورها واعتمادها يدويًا قبل أي نشر.
