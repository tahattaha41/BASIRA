# خطة BASIRA

هذه الخطة المختصرة نقطة دخول فقط. المرجع الشامل والملزم هو:
- docs/PROJECT_REFERENCE.md — الرؤية والمتطلبات والمشكلات والحلول.
- docs/STATUS.md — ما تم وما لم يتم ومعايير القبول.
- docs/DECISIONS.md — القرارات المعتمدة والمؤجلة.
- docs/REQUEST_LOG.md — سجل الطلبات.

## المنتج

BASIRA | بصيرة منصة عربية للمعرفة والألعاب الذهنية والتعلم الممتع. الشعار: Think. Discover. Play. / فكّر. اكتشف. العب.

يقتصر التصميم والتنفيذ على منصة BASIRA للمعرفة والألعاب وفق المرجع المعتمد.

## أولويات التنفيذ

1. توحيد فرع منصة المعرفة والألعاب كمسار تطوير معتمد.
2. استكمال قالب الواجهة الرئيسية وتجربته على Blogger والهاتف.
3. إكمال الألعاب الخمس: اختيار متعدد، صح/خطأ، ترتيب أحداث، ذاكرة، تخمين كلمة.
4. تجهيز أسئلة ومحتوى أصلي موثق ومراجع بشريًا ضمن الأقسام الثمانية.
5. اختيار مزود حسابات مجاني اختياري، ثم حفظ التقدم والنقاط بأمان.
6. إكمال صفحات الثقة وSEO واختبارات الأداء والخصوصية.
7. معاينة حية ثم تقرير جاهزية AdSense دون ضمان القبول.

- لا حذف بيانات أو صفحات قائمة.
