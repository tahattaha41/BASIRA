# خطة BASIRA المعتمدة — المرحلة الثانية

آخر تحديث: 2026-11-23

## الهوية والمنتج

- الاسم: **BASIRA | بصيرة**.
- الشعار: **Think. Discover. Play.** / **فكّر. اكتشف. العب.**
- المنتج: منصة عربية للمعرفة والألعاب، تعمل على Blogger.
- الاتجاه: واجهة هجينة بين مجلة معرفة ومنصة ألعاب، موبايل أولاً، RTL/LTR.
- الألعاب الخمس: اختيار متعدد، صح/خطأ، ترتيب الأحداث، الذاكرة، خمّن الكلمة.

## النطاق المعتمد

المراحل A إلى E معتمدة ونُفذت في المستودع الرئيسي عبر PRs #17 إلى #21، بعد إعادة البناء الأساسية في PR #13:

- **A — الأساس:** بنية القالب، الهيدر، البحث، اللغة، الوضع الداكن.
- **B — الصفحات:** صفحات المعرفة والبطاقات والصفحات التعريفية.
- **C — الألعاب:** المستويات، المؤقت، السلاسل، تلميح 50:50، الترتيب، تحدي اليوم، XP والإنجازات المحلية.
- **D — تحدي الأصدقاء:** رابط تحدٍ ببذرة مشتركة ومقارنة محلية؛ ليس نظاماً مضاداً للغش.
- **E — SEO والهوية:** وسوم SEO وبيانات منظمة ورسومات SVG وManifest محدود.

تفاصيل الدمج والاختبارات والقيود في `PHASE2_EXECUTION.md`.

## خارج النطاق

المرحلة F مستثناة حتى موافقة مستقلة:
- الحسابات وتسجيل الدخول.
- مزامنة التقدم بين الأجهزة.
- لوحة ترتيب رسمية أو منافسة موثقة بخادم.
- أي خدمة خارجية جديدة أو مدفوعة.

لا توجد إعلانات أو حسابات حالياً.

## المحتوى

- بنك الأسئلة الموجود هو المصدر الحالي؛ لا تضف أسئلة بلا مصادر وتفسير ومراجعة.
- المقالات الثمانية في `content/articles/` مسودات تحتاج مراجعة المالك قبل نشرها.
- النسخة الإنجليزية للمحتوى غير جاهزة للنشر؛ لا تنشئ hreflang إلا لأزواج ترجمة منشورة ومتحقق منها.
- لا تدّعِ أن كل مقال كُتب يدوياً إذا كان قد أُعد بمساعدة الذكاء الاصطناعي.

## قواعد النشر

- GitHub Actions يبني ويفحص عند تحديث `main`.
- بناء CI لا يساوي النشر على Blogger.
- Blogger API v3 يدير الصفحات والمقالات، ولا يوفر مورداً لرفع قالب XML؛ رفع القالب يظل من لوحة Blogger.
- نشر الصفحات عبر `basira-blogger-pages.yml` يدوي حالياً.
- لا تنشر مسودات المقالات تلقائياً.
- لا تضع مساراً في `src/site.json:published` قبل التحقق من الرابط الفعلي على Blogger.

## قبول الجودة

لا يُعلن اكتمال النشر قبل تجربة القالب والصفحات على Blogger الحقيقي، وفحص الهاتف الفعلي. نجاح الاختبارات المحلية لا يثبت عرض Blogger أو قبول AdSense أو عمل PWA دون اتصال.
