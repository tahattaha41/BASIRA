# خطة المنصة (مسودة للمراجعة)

## القرارات
- المحتوى: Blogger (قالب XML واحد مبني بسكربت).
- الألعاب: صفحة/صفحات ثابتة بجافاسكريبت خفيف، والأسئلة JSON مراجَعة.
- الحسابات: خدمة خارجية اختيارية (انظر `KEYS.md`). الزائر يلعب بلا حساب، والتقدم يُحفظ محلياً ثم يُزامَن عند التسجيل.
- لا ذكاء اصطناعي وقت التشغيل. الذكاء الاصطناعي مساعد تحرير فقط والمراجعة بشرية.

## المراحل
1. هيكل المستودع + سكربت بناء القالب + محاكي بلوجر + اختبارات.
2. القالب والتصميم (RTL، الهاتف أولاً) والصفحات الأساسية.
3. محرك الألعاب (5 ألعاب مكتملة أولاً) + أسئلة مراجَعة.
4. الحسابات والنقاط (التحقق من النتيجة على الخادم).
5. المحتوى المعرفي (8 أقسام، بمصادر).
6. SEO + تقرير جاهزية AdSense.
7. اختبارات فعلية وتسليم Pull Request.

## الألعاب (بالترتيب)
اختيار من متعدد، صح/خطأ، ترتيب أحداث، ذاكرة، تخمين كلمة. البقية بعد اكتمالها.

## نظام النقاط (قواعد معلنة)
نقطة لكل إجابة صحيحة، مكافأة سرعة صغيرة بسقف، لا نقاط لإعادة نفس الاختبار أكثر من مرة يومياً. يحسبها الخادم من الإجابات لا من رقم يرسله المتصفح.
