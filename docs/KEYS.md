# المفاتيح والخدمات

لا يُنشأ أي مفتاح قبل موافقة المالك. لا تُكتب أي قيمة في المستودع.

| المفتاح/الخدمة | الوظيفة | ضروري؟ | مكان التخزين | التكلفة |
|---|---|---|---|---|
| لا شيء (الألعاب والمحتوى) | عرض المقالات والألعاب | نعم | — | 0 |
| إعداد ويب لمزود الحسابات | تسجيل الدخول | اختياري (للحفظ بين الأجهزة) | عام بطبيعته؛ الحماية بقواعد الأمان | حد مجاني، يُتحقق منه قبل الاعتماد |
| مفتاح إداري/Service للخادم | التحقق من النتائج وكتابة النقاط | فقط إن فُعّلت الحسابات | أسرار الخادم، لا المتصفح ولا المستودع | داخل الحد المجاني |
| Turnstile (موقع + سرّي) | حماية التسجيل من الروبوتات | اختياري | السرّي في الخادم | مجاني |
| GEMINI_API_KEY | مسودات أسئلة ومقالات للمراجعة البشرية | اختياري، تحرير فقط | جهاز المحرر | الحصة المجانية، يُتحقق منها أولاً |
| Image/Search API | — | غير مطلوب | — | — |

مزود الحسابات: مقارنة قبل الاختيار (Firebase / Cloudflare Workers+D1 / Supabase) في المرحلة 4.
