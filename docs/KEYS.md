# المفاتيح والخدمات

لا تُكتب أي قيمة سرية داخل المستودع أو ملفات المصدر. تحفظ بيانات OAuth في GitHub Actions Secrets أو Environment Secrets.

## تكامل Blogger الحالي

الأسماء المستخدمة في workflows والسكربتات:

- `BLOGGER_BLOG_ID`
- `BLOGGER_CLIENT_ID`
- `BLOGGER_CLIENT_SECRET`
- `BLOGGER_REFRESH_TOKEN`
- `BASIRA_CONTACT_EMAIL`

سجل تشغيل workflow رقم 44966350885 بتاريخ 2026-11-22 أظهر أن أسرار OAuth الأربعة كانت متاحة للـ workflow، لكنه شُغّل بوضع `plan` فقط ولم ينشر شيئاً. كان `BASIRA_CONTACT_EMAIL` فارغاً في ذلك التشغيل.

لا يمكن استنتاج الحالة الحالية للأسرار من المستودع؛ يجب التحقق من إعدادات GitHub دون كشف قيمها.

## حدود التكامل

- Blogger API v3 يدعم موارد Posts وPages وBlogs وغيرها كما في الوثائق الرسمية، لكنه لا يوفّر مورداً لرفع أو تحديث قالب Blogger XML.
- لذلك لا يمكن جعل كل تعديل في `src/theme.tpl.xml` يظهر تلقائياً على Blogger عبر Blogger API الرسمي. يجب رفع `dist/theme.xml` من لوحة Blogger.
- يمكن أتمتة صفحات Blogger الثابتة بعد ضبط OAuth، مع حماية صفحة الاتصال من النشر قبل توفير بريد صالح.
- لا تنشر مسودات المقالات آلياً؛ تحتاج مراجعة المالك.

## خدمات غير مفعّلة

| الخدمة | الغرض | الحالة |
|---|---|---|
| تسجيل الدخول/الحسابات | مزامنة التقدم | المرحلة F مستثناة |
| قاعدة بيانات خارجية | لوحة ترتيب موثقة | المرحلة F مستثناة |
| Turnstile | حماية التسجيل | غير مستخدم |
| Gemini API | مساعدة تحريرية | غير مطلوب وقت تشغيل الموقع |
| Image/Search API | جلب الصور | غير مطلوب حالياً |

لا تنشئ حسابات أو خدمات أو مفاتيح جديدة دون موافقة مستقلة.
