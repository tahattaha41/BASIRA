## المشكلات والحلول المطلوبة

1. **الواجهة الحالية لا تحقق الرؤية Hybrid:** بناء Design System موحد ثم تطبيقه على الرئيسية والأقسام والألعاب والمقالات، مع اختبار الهاتف.
2. **غياب الإنجليزية:** إضافة قاموس ترجمة مركزي ومحتوى إنجليزي حقيقي لكل واجهة ولعبة، وربط مبدّل اللغة بالمسار/المعامل الحالي مع حفظ الاختيار.
3. **الألعاب تبدو متشابهة أو مملة:** الحفاظ على الأنواع الخمسة الأصلية، لكن إعطاء كل لعبة آلية لعب وشخصية مستقلة، وجولات قصيرة وصعوبة متدرجة ونتائج وإعادة لعب.
4. **لا توجد منافسة اجتماعية حقيقية:** تصميم تحديات قابلة للمشاركة ولوحة أسبوعية بعد اختيار مخزن نتائج موثوق؛ لا تعرض ترتيباً تجريبياً كأنه حقيقي.
5. **الحسابات والمزامنة غير موجودة:** إبقاء اللعب كضيف أولاً، ثم إضافة التسجيل الاختياري دون ربطه بحساب الإدارة.
6. **غياب تحقق Blogger الحقيقي:** فحص القالب XML والبناء آلياً لا يثبت نجاح عرضه على Blogger؛ يلزم اختبار رفع يدوي ومراجعة الصفحات والروابط قبل أي نشر.
7. **تراجع تغطية المتصفح في PR #13:** استعادة browser_test أو إضافة تغطية مكافئة، بجانب game_test.
8. **التقرير كان موزعاً بين PRs:** هذا الملف يصبح لوحة الحالة الموحدة، ويحدّث سجل النشاط تلقائياً عند تغييرات Git بعد دمج أتمتة التقرير.
