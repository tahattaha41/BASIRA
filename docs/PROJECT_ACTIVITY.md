# نشاط المستودع — تحديث آلي

يُحدّث هذا الملف بواسطة GitHub Actions بعد كل push إلى أي فرع، وعند تسجيل طلب GitHub جديد.

- **الحالة:** ينتظر أول تشغيل ناجح بعد دمج workflow.
- **النطاق:** يسجل الفرع وآخر commit ومساراته المتغيرة؛ لا يستنتج اكتمال الميزات.
- **سجل الطلبات:** GitHub Issues المفتوحة/المعدلة/المعاد فتحها تُسجل في docs/REQUEST_LOG.md.
- **حد مهم:** الطلبات المرسلة في محادثات خارج GitHub لا يمكن التقاطها آليًا؛ يجب تسجيلها كـ Issue أو إدخالها في سجل الطلبات.
- **الحالة الوظيفية:** تُحدّث docs/STATUS.md وdocs/PROJECT_REFERENCE.md يدويًا داخل PR بعد التحقق، لأن Git لا يستطيع استنتاج أن ميزة أصبحت مكتملة من أسماء الملفات أو commit وحده.
