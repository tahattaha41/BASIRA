# BASIRA brand assets

- `basira-symbol.svg`: standalone symbol.
- `basira-horizontal.svg`: horizontal wordmark with Arabic name and English tagline.
- The Blogger theme embeds the symbol inline through `scripts/ui.py`, so the live theme does not depend on a third-party image host.
- Official name: **BASIRA | بصيرة**.
- Official tagline: **Think. Discover. Play.** / **فكّر. اكتشف. العب.**
